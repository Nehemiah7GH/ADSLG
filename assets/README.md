This directory should contain the following image assets for the application:

## Required Assets

1. **icon.png** - App icon (1024x1024px recommended)
   - Square icon used for app stores
   - Should feature musical notes or hymnal-related imagery
   - Colors: Royal blue (#1E3A8A) and gold (#D4AF37)

2. **adaptive-icon.png** - Android adaptive icon (1024x1024px)
   - Should have transparent background
   - Icon should be centered within safe zone

3. **splash.png** - Splash screen image (2048x2048px recommended)
   - Background: Royal blue (#1E3A8A)
   - Can include app name "À DIEU SOIT LA GLOIRE"
   - Should include musical or spiritual imagery

4. **favicon.png** - Web favicon (48x48px or larger)
   - Simplified version of the app icon

## Design Guidelines

- Use the spiritual color palette: Royal Blue (#1E3A8A), Gold (#D4AF37), White (#FFFFFF)
- Include musical notes, hymnal book, or cross imagery
- Keep designs clean and modern
- Ensure good contrast for visibility
